# Pasta de imagens

Envie aqui as imagens do site com os nomes exatos indicados no README.md (secção 4).
Enquanto um ficheiro não existir, a página mostra um bloco colorido com o nome em falta.
Capas dos artigos: pasta `img/blog/` (nome = endereço do artigo + .jpg).
Formatos: JPG ou WebP, ~100–200 KB cada.
