# Proposta Técnica iTpraTi - Migração Cloud PEGOS

## Descrição do Projeto

Este projeto contém uma proposta técnica e comercial completa para migração da infraestrutura da PEGOS para a Cloud, desenvolvida pela **iTpraTi - Internet e Tecnologias**.

A proposta foi criada como uma página web moderna, responsiva e profissional, pronta para apresentação ao cliente.

## Características da Proposta

### 🎨 Design Moderno e Profissional
- Layout responsivo que funciona em desktop e mobile
- Gradientes e animações suaves
- Navegação sticky com scroll suave
- Cards interativos com efeitos hover
- Timeline visual para o cronograma de implementação

### 📊 Conteúdo Técnico Completo
- **Objetivo:** Modernização da infraestrutura de TI
- **Diagnóstico:** Análise da situação atual distribuída
- **Solução:** Duas opções de servidores cloud (2 servidores ou solução unificada)
- **Benefícios:** 6 benefícios principais com ícones
- **Investimento:** Tabelas de preços transparentes
- **Implementação:** Timeline de 15 dias úteis

### 🛠️ Tecnologias Utilizadas
- HTML5 semântico
- CSS3 com variáveis customizadas
- JavaScript vanilla para interatividade
- Font Awesome para ícones
- Google Fonts (Inter)
- Design responsivo com CSS Grid e Flexbox

## Como Usar

### Visualização Local
1. Faça o download do arquivo `proposta_itprati_web.html`
2. Abra o arquivo em qualquer navegador web moderno
3. A proposta será exibida com todas as funcionalidades

### Publicação Online
1. Faça upload do arquivo HTML para qualquer servidor web
2. Ou use serviços como GitHub Pages, Netlify, ou Vercel
3. A página funcionará perfeitamente sem dependências externas

### Personalização
- Todas as cores estão definidas em variáveis CSS no início do arquivo
- Conteúdo pode ser facilmente editado no HTML
- Design é totalmente responsivo

## Especificações Técnicas da Proposta

### Opção 1: Dois Servidores
- **Servidor 1 (ERP):** AMD EPYC 4345P, 64GB RAM, 4×960GB SSD
- **Servidor 2 (AD):** AMD EPYC 4245P, 32GB RAM, 2×960GB + 2×1.92TB SSD
- **Custo Total:** 1.113.826,00 Kz/mês + 1.198.800,00 Kz instalação

### Opção 2: Solução Unificada
- **Servidor 3:** AMD EPYC 4465P, 128GB RAM, 4×1.92TB SSD
- **Custo Total:** 997.520,00 Kz/mês + 1.076.400,00 Kz instalação

### Cronograma de Implementação
- **Fase 1:** Planeamento (3 dias)
- **Fase 2:** Configuração (10 dias)
- **Fase 3:** Migração (2 dias)
- **Total:** 15 dias úteis
